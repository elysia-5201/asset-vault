## 2. 发现（F1–F8）

| ID | 严重度 | 发现 | 证据 | 影响 |
|---|---|---|---|---|
| **F1** | **高** | **导入内容不做风险扫描**：不检查 .cs/.dll/.asmdef/Editor 目录/可执行/脚本，也不校验"扩展名 vs 魔法"（重命名的 zip 当 upkg、MZ 冒充 pdf 等） | 结构单元只有 `policy/importable/parse_state/avatar_json` 与 `evidence.reason`（`structure.ts:223-312`）；precheck 只看指纹/存在/策略（`:572-597`）；`importPackagesIntoUnity` 直接 `AssetDatabase.ImportPackage`（`unity.ts:371-390`） | 用户可能把含编辑器脚本/原生 DLL 的包直接导入工程；Unity 会执行 Editor 脚本 → **安全风险**；"看起来是 pdf 实际是包"可绕过预期 |
| **F3** | **高** | **staging 无生命周期管理**：每次执行 `mkdtemp` 落盘、无清理/无总量上限/无活跃保护；`stageUnityPackage` 用固定 `stagingDir/assetId` 目录（同名复用时可能覆盖/残留） | `structure.ts:160-166`；`unity.ts:348-360`；全仓 grep 无 staging prune（仅 `cache.pruneTemp`） | 磁盘无界增长；中断/崩溃后残留；重复导入复用同名目录可能读到旧解压内容 |
| **F6** | 中 | **无构建一致性校验**：bundle 是否含新路由、schema.sql 是否同步、版本/时间是否与源码匹配，全靠人工 | `apps/desktop/build.mjs:11-20`；v0.6.2 曾出现部署树 CLI bundle 陈旧（Electron 包正确）的历史问题 | 部署"看起来成功"但 CLI 运行旧代码/旧 schema；验收无法自动发现 |
| **F5** | 中 | **MCP 探测无缓存/无集中超时**：`unityClientFor` 每次构造 URL 列表，`unityEditorInfo` 每次执行都重新探测；多单元/多请求重复等待失败 | `unity.ts:22-26`、`:222-234` | 无 Unity 时每个请求都等 fetch 失败（本机 fetch failed 很快，但仍重复）；无探测结果缓存 |
| **F7** | 中 | **取消/中断的单元级状态不完整**：job 被 cancel 时外部 `ImportPackage` 已发出不可撤回；`markImportInterrupted` 只改 run/plan，run_items 可能停在 importing（逐单元 catch 才写 failed） | `runner.ts:420-436`、`structure.ts:604-627`（recordPreflightFailure）、执行循环 `:675+` | 取消后的 run 明细可能"半开"；审计/重试判断依赖 plan.status |
| **F4** | 低-中 | **手动 retry 语义不显式**：`/api/jobs/:id/retry` 对任意失败 job 放行（含 import）；因 plan=failed，重试会在 precheck 处被 `PLAN_NOT_EXECUTABLE` 拒绝，**不会重复外部导入**，但会再落一条 failed run（recordPreflightFailure） | `routes.ts:902`；`structure.ts:578-580`、`:604-627` | 安全（无重复导入）但语义含糊/审计噪音；应为 import 显式 409 或前端隐藏重试 |
| **F2** | 已满足 | mixed 必须人工确认（needs_confirmation）；unknown/limited 不可导入；**不自动重试** | `structure.ts:451-452`、`:26`、`:578-580`；`runner.ts:421-436` | 符合本轮 A/B/C 策略；验收需钉住防回归 |

## 3. 已具备的正面约束（本轮必须保持）

1. **mixed 不拆**：计划 path=原始整包、rel_path 指包内条目；`needs_confirmation`（structure.ts:451-452）。
2. **unknown 不导入、不伪造**：unknown_structure/limited → importable=0（structure.ts:26/218/263/345），建计划 INVALID_INPUT。
3. **不自动重试外部导入**：import job 失败/中断 → run interrupted、plan failed，不重放（runner.ts:421-436；precheck 拒绝 executed/failed，structure.ts:578-580）。
4. **指纹变化阻断**：precheck FINGERPRINT_CHANGED + plan blocked（structure.ts:583-590）。
5. **边界**：depth=3 / 32 容器 / 512MB / 45s / 5000 条目（structure.ts:79-131），超限 limited 不伪造成功。
6. **Unity 命令完成≠验证成功**：run_items 有 verifying/verified/partial_success 分层（structure.ts:646-700+）。
7. **工作台探测一次/静默**（v0.7.1，commit e10ceed）：`AvatarWorkbench.tsx:300-363`。
