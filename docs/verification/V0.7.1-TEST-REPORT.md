- 夹具：Python 现场生成真实 tar.gz unitypackage 与 zip：干净包、风险包（cs/dll/Editor/asmdef）、大小写反斜杠包、伪装包（pdf→PK、png→MZ）、真实 .pdf 内容为 zip（计划级 magic）、损坏包；不 mock 解析层。
