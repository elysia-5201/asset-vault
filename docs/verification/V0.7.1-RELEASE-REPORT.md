## 6. 发布判断与建议

**不建议以当前 Windows 目录直接发布 0.7.1。** 阻塞项：

1. **D1** Electron exe 版本 0.6.2（payload 0.7.1）→ 需在目标 commit 重新 electron-builder。
2. **D2** 部署根 Web 是 0.6.2 旧包 → 需重建根 Web（或统一用发布包部署）。
3. **D3** 部署根源码混合（App.tsx/工作台缺失）→ 需从单一 commit 重新部署。
4. **T1** 当前工作树 10 个测试失败（未提交 v9/WIP）→ 发布必须基于干净、全绿的 commit。
5. **U1** Unity 真实导入未验收（BLOCKED）→ 发布说明只能写 UNVERIFIED，不能写“导入已验收”。

建议动作：切到目标 release commit → `npm test` 全绿 → `build:web` + `desktop:bundle` + `desktop:dist`（确认 exe 版本）→ 用发布包统一部署/生成 zip+sha256 → 在隔离工程副本执行 Unity 导入验收 → 再更新本报告。若本轮不打算发版，建议 bump 0.7.2 并只发布修复后的构建。
