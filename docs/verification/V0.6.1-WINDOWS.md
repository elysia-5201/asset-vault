## 1. 环境审计（2026-10-20，原始输出摘录）

### 1.1 WSL → Windows 通路
```
$ ls -l /mnt/c/Windows/System32/cmd.exe /mnt/c/Windows/System32/WindowsPowerShell/v1.0/powershell.exe
-r-xr-xr-x 2 root root 450560 ... powershell.exe
-r-xr-xr-x 2 root root 327680 ... cmd.exe

$ /mnt/c/Windows/System32/cmd.exe /c ver
Microsoft Windows [版本 10.0.22631.6199]          (rc=0)

$ powershell.exe -NoProfile -Command '$PSVersionTable.PSVersion.ToString()'
5.1.22621.6133
```
两个硬坑（脚本必须规避）：
1. **cmd.exe 从 WSL 启动时 cwd 是 UNC 路径**，会打印"UNC 路径不支持，默认设为 Windows 目录"→ 所有 Windows 命令必须显式 `cd /d`。
2. **bash 双引号会展开 PowerShell 的 `$_`/`$env:`**（实测 `$_.ProcessName` 变成 `bash.ProcessName`），且 PowerShell 读 stdin 用 CP936 会撕碎中文脚本。
   稳定写法：脚本写 UTF-8 → `iconv -t UTF-16LE | base64 -w0` → `powershell.exe -NoProfile -EncodedCommand <b64>`。本轮所有 Windows 探测与脚本均按此执行。

### 1.2 挂载与写权限
```

$ touch /mnt/e/__av_write_test
```
